## คุณสมบัติเด่น

| | ฟีเจอร์ | หน้าที่ |
|---|---|---|
| 🔍 | **Search + Auto-summary** | ช่องค้นหาเดียวครอบคลุมโรค sign และชื่อพ้อง การ์ด Auto-summary แสดง best match, ตำแหน่งรอยโรค, รายการ "Also consider" และการตรวจแรกในหน้าเดียว |
| ⚖️ | **Compare** | วางโรคที่คล้ายกันเทียบข้างกัน บรรทัด "how to tell apart" เขียนไว้สำหรับคู่โรคที่สับสนบ่อย |
| 📚 | **หน้าโรค** | โครงเดียวกันทุกหน้า: At a glance, Features, Tests, In depth, Case, Questions, Differential, Similar, Signs, Read เลือกนิยามได้ทั้ง Formal, Simple และไทย |
| 🧠 | **ทบทวนแบบ active recall** | Cloze it, Gush! (flash card), Quiz และ Board MCQ เปลี่ยนเนื้อหาเดียวกันเป็นการฝึกดึงความจำ |
| 🗂️ | **Browse และ Shadow a book** | ทบทวนตามกลุ่มโรค ตำแหน่งรอยโรค หรือ tempo หรือจับคู่ฐานข้อมูลกับตำราที่กำลังอ่าน |
| 📴 | **ออฟไลน์** | ใช้งานได้โดยไม่ต้องมีอินเทอร์เน็ตหลังติดตั้ง ตรวจอัปเดตเมื่อมี Wi-Fi |
| 🔒 | **ออกแบบเพื่อความเป็นส่วนตัว** | ไม่มีการลงทะเบียนผู้ป่วยหรือสั่งการรักษา รายการที่บันทึกและประวัติอยู่ในเครื่องเท่านั้น |

## เนื้อหาในแอป

- มากกว่า **2,500 โรค** และ **760 sign** ทางประสาทวิทยา
- นิยาม ตำแหน่งรอยโรค การตรวจสำคัญ สรุปเชิงลึก differential และเอกสารอ้างอิง
- **เคสสอนสมมติ** และ **ข้อสอบแบบ board** (ผู้ป่วยทุกรายเป็นสมมติ)
- สรุปภาษาไทยควบคู่กับเนื้อหาภาษาอังกฤษ
- ดัชนีตำราอ้างอิง (มากกว่า 200 เล่ม) สำหรับโหมด *Shadow a book*

## เริ่มต้นใช้งาน

1. เปิดแอป: https://YOUR-USERNAME.github.io/YOUR-REPO/
2. พิมพ์อาการแสดง sign หรือชื่อโรคในช่องค้นหา (บนคีย์บอร์ดกด `/` เพื่อไปที่ช่องค้นหา)
3. อ่านการ์ด **Auto-summary** ก่อน แล้วเปิด best match

## ติดตั้งเป็นแอป (ใช้ออฟไลน์)

1. เปิดแอปในเบราว์เซอร์ (ต้องเป็น HTTPS จึงจะติดตั้งได้)
2. แตะ **ไอคอนแถบเลื่อน** (มุมขวาบน) เพื่อเปิด **Settings**
3. ที่ **Install for offline use** กด **How to install** แล้วทำตามขั้นตอนสำหรับมือถือหรือคอมพิวเตอร์ของคุณ
4. เมื่อมีอินเทอร์เน็ต ไปที่ **Lexicon updates → Check for updates** แนะนำให้ทำสัปดาห์ละครั้งเมื่อมี Wi-Fi

## คู่มือใช้งานทีละขั้นตอน

### A. ค้นหาโรคหรือ sign ข้างเตียง / ER

เปิดแท็บ **Search** พิมพ์อาการแสดง sign หรือชื่อโรค (เช่น "cancer stroke") แล้วอ่านการ์ด **Auto-summary**: best match, ตำแหน่งรอยโรค, กลุ่มโรค, รายการ "Also consider" และการตรวจแรก เมื่อยังไม่ทราบการวินิจฉัย ให้ค้นด้วยอาการแสดงแทนชื่อโรค (เช่น "ptosis miosis")

<p align="center">
  <img src="docs/images/search.png" width="280" alt="รูปที่ 1: หน้าค้นหา">
</p>

### B. อ่านหน้าโรค

ดูป้ายด้านบน (**curated**, **Draft · วันที่**, ป้ายเขียวเมื่อมีข้อมูลเชิงลึก) เลือกรูปแบบนิยาม (Formal / Simple / ไทย) แล้วใช้แถบลัดเพื่อกระโดดไปยังหัวข้อต่าง ๆ ส่วน **In depth** ครอบคลุม pathophysiology, อาการทางคลินิก, การวินิจฉัย, การรักษา, พยากรณ์โรค และ pearls

<p align="center">
  <img src="docs/images/disease-header.png" width="260" alt="รูปที่ 2: ส่วนหัวของหน้าโรค">
  <img src="docs/images/in-depth.png" width="260" alt="รูปที่ 3: ส่วน In depth">
</p>

> 💡 ตรวจเร็วข้างเตียงให้อ่านเพียง **At a glance → Key investigations → Treatment** แล้วค่อยกลับมาอ่าน *In depth* หลังเวร

### C. เคสสอนและข้อสอบแบบ board

กระโดดไปที่ **Case** อ่านผู้ป่วย ประวัติ การตรวจ และผลตรวจ ตอบในใจก่อนแล้วกด **Show answer** จากนั้นไปที่ **Questions** เพื่อทำข้อสอบปรนัย เฉลยและคำอธิบายจะแสดงหลังตอบ

<p align="center">
  <img src="docs/images/case.png" width="260" alt="รูปที่ 4: เคสสอน">
  <img src="docs/images/questions.png" width="260" alt="รูปที่ 6: ข้อสอบแบบ board">
</p>

### D. ทบทวนแบบ active recall: Cloze it, Gush! และ Quiz

- **Cloze it:** เปิดสวิตช์ที่แถบบนเพื่อซ่อนคำสำคัญ แตะที่ช่องว่างเพื่อเปิดดู
- **Gush!:** เลือกชนิดการ์ด (Diseases, Signs, Case quiz, Neuroscience) กด **Start Gush!** แตะการ์ดเพื่อพลิก ปัดขึ้นเพื่อไปใบถัดไป การ์ดที่ไม่มั่นใจจะกลับมาเร็วขึ้น
- **Quiz:** เลือก Flashcards, Quiz หรือ Board MCQ และกรองตามกลุ่มโรค

<p align="center">
  <img src="docs/images/cloze.png" width="230" alt="รูปที่ 7: เปิด Cloze it">

  <img src="docs/images/quiz.png" width="230" alt="รูปที่ 9: แท็บ Quiz">

> ⚠️ อย่าลืม **ปิด Cloze it** ก่อนใช้หน้าโรคเพื่อดูแลผู้ป่วย คำที่ถูกซ่อนอาจทำให้เข้าใจผิดว่าเนื้อหาขาดหาย

### E. เปรียบเทียบโรคที่คล้ายกัน

ในหน้าโรคกด **Compare** เพิ่มโรคที่สอง (จากรายการแนะนำหรือช่องค้นหา) แล้วเปิดแท็บ **Compare** อ่านเทียบรายแถว โรคที่เลือกก่อนเป็นคอลัมน์อ้างอิง

### F. Browse และ Shadow a book

เปิด **Browse** แล้วเลือกโหมด: By group, By localization, By tempo, Diseases A–Z, Signs A–Z, Biomarkers, Pathogens, Neuroscience, Curated หรือ Status ใช้ **Shadow a book** เพื่อเลือกตำราอ้างอิงและดูหน้าที่อ้างตำรานั้น ซึ่งจัดกลุ่มตามบทหรือเคส

</p>

> 💡 ก่อนขึ้นเวรดึก ใช้ Browse ตาม **tempo → acute** เพื่อดูรายการโรคที่ต้องตัดสินใจเร็ว

### G. รายการที่บันทึก ประวัติ และการอัปเดต

กด **Save** ที่หน้าใดก็ได้ แล้วดูภายหลังที่แท็บ **Saved** ส่วน **History** แสดงหน้าที่เปิดล่าสุด รายการที่บันทึกเก็บเฉพาะในเครื่องนี้ และจะหายหากล้างข้อมูลเบราว์เซอร์หรือติดตั้งแอปใหม่

## ความเป็นส่วนตัว

Sanctum ไม่มีการลงทะเบียนผู้ป่วย สั่งการรักษา หรือแสดงผลตรวจ และไม่เก็บข้อมูลผู้ป่วย รายการที่บันทึกและประวัติอยู่ในอุปกรณ์ของคุณเท่านั้น **ห้ามใส่ข้อมูลระบุตัวตนผู้ป่วยในช่องบันทึกใด ๆ**

## รันในเครื่อง / นำไปเผยแพร่เอง

เป็นเว็บแอปแบบ static จึงไม่ต้อง build เนื่องจากใช้ service worker และโหลดไฟล์ข้อมูล ให้เปิดผ่านเว็บเซิร์ฟเวอร์ในเครื่อง แทนการดับเบิลคลิก `index.html`:

```bash
# รันที่โฟลเดอร์รากของ repository
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เผยแพร่ด้วย GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save** เว็บจะอยู่ที่ `https://YOUR-USERNAME.github.io/YOUR-REPO/`

เคล็ดลับ: หากแก้ไฟล์ข้อมูลแล้วผู้ใช้ไม่เห็นเนื้อหาใหม่ ให้เพิ่มเลขเวอร์ชันใน `data/version.json` แล้วให้ผู้ใช้กด **Check for updates**

## ข้อสงวนสิทธิ์

เนื้อหาเพื่อการศึกษา และบางส่วนมีป้าย **Draft** รอผู้เชี่ยวชาญตรวจ ข้อความที่ผู้จัดทำติดธงว่าเป็นความรู้ทั่วไปยังไม่ได้ตรวจเทียบกับแหล่งที่อ้าง ต้องตรวจสอบขนาดยา ข้อห้ามใช้ และแนวทางของสถาบันก่อนตัดสินใจทางคลินิกทุกครั้ง เคสทั้งหมดเป็นสมมติ ห้ามนำรายละเอียดเคสไปบันทึกในเวชระเบียน การมีตำราอยู่ในรายการหมายถึงใช้เป็นแหล่งอ่านเท่านั้น ไม่ได้คัดลอกเนื้อหา และต้องอ้างอิงจากต้นฉบับเสมอ
